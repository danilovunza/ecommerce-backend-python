# E-Commerce Backend

## Overview

The E-Commerce Backend is a Python application developed using Object-Oriented Programming principles, inheritance, and composition.

The system simulates the backend operations of an online store.

---

## Features

* Product Catalog
* Shopping Cart
* Checkout System
* Payment Processing
* Order History

---

## Classes

### Person

Base class.

### Customer

Inherits from Person.

### Product

Stores product information.

### ShoppingCart

Manages selected products.

### Payment

Handles payment information.

### Order

Stores completed order data.

---

## OOP Concepts

### Inheritance

Customer inherits from Person.

### Composition

Orders contain Customers, Products, and Payments.
